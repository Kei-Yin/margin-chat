# Margin · ChatGPT 旁注

Chrome / Edge Manifest V3 扩展。选中 ChatGPT 回答文字 → 独立追问 → 原文高亮 → 点击回看。主聊天不新增消息。

## 1. 安装扩展（不需要编译）

1. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
2. 开启「开发者模式」，选择「加载已解压的扩展程序」。
3. 选择本项目的 **extension 文件夹**，不是项目根目录。
4. 刷新已打开的 ChatGPT 网页，将 Margin 固定到浏览器工具栏。

## 2. 先体验交互

点击扩展图标，勾选「演示模式」，点击保存。在 `https://chatgpt.com/c/...` 的已保存聊天中选中一段助手回答，点击「追问这段」。演示模式只返回明确标注的固定示例，不调用 AI。刷新后仍会恢复批注。主聊天中的输入框和消息不会被修改。

## 3. 接入真实回答

需要 Node.js 22+、OpenAI API 密钥以及你的 API 账户可用的模型 ID。本扩展使用独立 API 请求，不使用 ChatGPT 登录凭据或订阅额度。

在项目目录复制 `.env.example` 为 `.env`，编辑：

```
OPENAI_API_KEY=你的密钥
OPENAI_MODEL=你的模型ID
MARGIN_TOKEN=可选的长随机配对码
```

运行：

```
npm start
```

将终端显示的配对码粘贴到扩展设置，关闭演示模式，保存，点击「检查服务」。未设置 MARGIN_TOKEN 时每次启动都会生成新配对码。保持终端运行即可。密钥只在本机 Node 服务内使用，不保存到网页或扩展。无需 npm install。

## 使用

- v0.1.3：根据真实页面诊断新增 `MarkdownRoot-*` 正文识别，兼容没有作者属性的 CSS Modules 布局；包含 v0.1.2 的焦点修复和诊断入口。

- v0.1.2：移除会误判选区的面板焦点检查；面板显示版本号，并提供「追问当前选区」和「检查选区」。诊断只显示区块数、选区字数及元素结构，不包含聊天正文，也不自动上传。

- 选中同一条助手回答中的文字，点击追问按钮。
- v0.1.1：兼容同一回答的多个 Markdown 区块，并使用捕获阶段和 selectionchange 检测选区。选中后右下角也会变为「追问选中文字」；也可按 Alt + Shift + M 直接创建旁注。
- 更新本地代码后，必须在扩展管理页面点击 Margin 的「重新加载」，再刷新 ChatGPT 标签页；仅刷新网页不会更新已经运行的扩展。
- 浮窗支持多轮问答；Ctrl / Cmd + Enter 发送。
- 点击高亮打开已有批注；右下角「旁注」显示当前聊天的列表，可搜索原文和问答。
- 删除操作只删除该批注；扩展设置可导出 JSON 备份（当前版本未提供导入界面）。
- 请求失败时问题仍会保留；修复设置后可在输入框重新发送。

## 边界与数据

- 本地保存，无云同步、无 Windows 原生客户端集成。卸载前请导出备份。
- 当前适配标准 `/c/聊天ID` 页面及助手消息的 `data-message-author-role` / `.markdown` 结构；临时聊天、分享页及非标准路径暂不支持。
- 原文定位优先使用消息 ID，再匹配引文和前后文。遇到相同引文无法消歧、修改原文、切换回答分支或历史消息未加载时，批注仍在列表里但不强行高亮。
- 使用 CSS Custom Highlight API，不改动 React 管理的原文 DOM。网页结构更新可能需要维护选择器。
- 向 OpenAI 发送选中文字、附近最多前后各 3500 字上下文以及该批注历史。API 请求设置 `store:false`，不代表零保留政策。不会发送整条主聊天、Cookie 或登录令牌。
- 当前回答按纯文本显示，保留换行；尚未提供 Markdown / 数学公式渲染、流式输出、附件理解。这样返回内容不会被当成 HTML 执行。
- 每条批注最多 100 条历史消息。单次问题最多 6000 字。服务最多并行 3 个请求；为避开 MV3 后台等待响应的生命周期限制，API 超时设为 23 秒，慢速模型可能需要重试；超时会保留已提交问题。

## 开发与验证

`npm test` 运行原文定位、请求构造、API 错误处理、后台保存、聊天隔离及请求并发测试。`node --check extension/content.js` 可检查语法。

运行 `node demo/serve.mjs`，打开 `http://127.0.0.1:43128/c/demo` 可体验本地交互试验台。它运行同一套 UI 与后台代码，以 localStorage 模拟 Chrome 存储；不等同于真实扩展安装测试。

真实 ChatGPT DOM 适配和真实 API 账户请求需要安装扩展后验证；没有配置 API 密钥时不能视为已完成真实模型联调。

结构：`extension/` 为浏览器扩展，`server/` 为仅监听 `127.0.0.1:43127` 的 API 代理，`tests/` 为无外部依赖测试。
